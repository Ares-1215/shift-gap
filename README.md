# 班次空檔分析（shift-gap）

上傳「運務通知（班次調整計畫）.docx」（內嵌班次表 Excel）或班次表 .xlsx，
找出每台車頭（曳引車／全拖車）**兩班之間停在同一站的空檔**，
並依班表反推的站間車程列出「來回＋掛卸作業」放得進空檔的**鄰近站所**，
讓調度可以用在站空等的車頭跑加班，不必另叫車頭空趟過來。

- 網站：https://ares-1215.github.io/shift-gap/ （全部在瀏覽器端解析，檔案不上傳到任何伺服器）
- 一鍵下載分析 Excel（說明／空檔_日期／站所別_日期／時間軸_日期／站間車程）

## 規則

| 項目 | 說明 |
|---|---|
| 讀取範圍 | 只讀「曳引車」「全拖車」分頁；每台車頭 5 列（班次代號／附掛車廂／到離時間／到離站所／備註），續接列接在同一台 |
| 底色 | 白＝原班次、黃＝新增或調整、綠＝刪減（排除）。分析「調整後」班表 |
| 空檔 | 同車頭相鄰兩個時間點同站，停留 ≥ 門檻（預設 60 分）；跨午夜自動加一天 |
| 日初待命 | 空檔前沒有班次代號（報到後等出車／放空櫃等同站作業），預設排除、可勾選顯示 |
| 站間車程 | 由上傳班表實際班次「出發→到達」時間差取中位數（下限 5 分） |
| 可跑站所 | 去程＋回程＋作業緩衝（預設 30 分）≤ 空檔分鐘，由近到遠；括號為來回合計分鐘 |

## 離線版（Python）

```bash
pip install openpyxl olefile
python tools/analyze.py "運務通知(班次調整計畫)(1105).docx" "運務通知_班次調整計畫_1106.docx" -o 班次空檔分析.xlsx --min 60 --buffer 30
```

`tools/parse_shift.py` 解析工作表，`tools/analyze.py` 計算與輸出；網頁 `index.html` 是同一套邏輯的 JavaScript 版本。

## 本機測試

```bash
python -m http.server 8765 --directory .
# 開 http://localhost:8765/?load=data/1105.docx,data/1106.docx （data/ 不入庫）
```
